# Windows Server Lab – Group Policy Configuration
Project Overview

This project is a continuation of my Windows Network Lab, where I set up a virtual network environment using Oracle VirtualBox, Windows Server, and a Windows client machine.

<img width="1920" height="983" alt="Yes" src="https://github.com/user-attachments/assets/06e1ea18-27fc-4516-84cf-0ef0f5b6dd31" />


Building on the existing Active Directory Domain Services (AD DS) environment, I implemented basic Group Policy Objects (GPOs). Configurations Implemented:

- Password Policy
- Desktop Wallpaper
- Shared Network Drives
- Control Panel Restriction
